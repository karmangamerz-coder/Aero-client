# Community Code of Conduct

Treat contributors and users with respect regardless of background, identity,
experience or disability. Be constructive, acknowledge mistakes and focus criticism
on ideas and code. Help newcomers and respect privacy.

Harassment, discriminatory language, threats, sexual harassment, doxxing, spam and
retaliation are unacceptable in issues, pull requests, discussions or project events.

Report concerns privately to repository maintainers using the private contact channel
listed on their GitHub profiles. If none exists, request a contact without posting
sensitive details publicly. A public project must establish a monitored private
moderation channel before opening community discussion spaces.

Maintainers will review reports confidentially as practical, recuse themselves when
involved and explain decisions to affected participants when safe. Enforcement may
include a correction request, warning, temporary restriction or permanent ban,
proportionate to severity and repeated behavior. Appeals may be sent privately to
an uninvolved maintainer. These standards apply to maintainers as well as contributors.
